# EmojiPilot

An Android Accessibility Service that automatically detects and replaces text shortcuts (such as `:fire:`, `:rocket:`, and `:smile:`) with their corresponding emojis across any editable text field.

## Cloud Build (GitLab CI/CD)
This repository includes a `.gitlab-ci.yml` file. When uploaded to GitLab, GitLab CI/CD will automatically compile `app-debug.apk` in the cloud using the Android SDK 34 Docker image.
